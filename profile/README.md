# Shopyos

Shopyos is a technology company building innovative digital products and platforms for commerce, businesses, and consumers.

## What We Build

We build products and infrastructure that make commerce and digital business simpler, more accessible, and more connected.

Our current ecosystem includes:

* **Shopyos Marketplace** — A marketplace connecting buyers, sellers, and delivery partners.
* **Shopyos Platform** — The technology and infrastructure powering our products and services.
* **Shopyos Developer Tools** — Shared libraries, APIs, and engineering tools used across our products.

As Shopyos grows, we will continue building products across commerce, business software, logistics, payments, AI, and other digital services.

## Engineering

Our engineering organization focuses on:

* Reliable and scalable systems
* Reusable software and shared components
* Secure development practices
* Clean and maintainable code
* Automated testing and deployment
* Consistent user experiences across products
* Documentation and clear technical decisions

## Technology

Our technology stack evolves with the needs of our products. Our current engineering ecosystem includes technologies such as:

* React Native
* Node.js
* PostgreSQL
* Redis
* Docker

* Railway
* Vercel

## Repositories

Our GitHub organization contains the source code, shared libraries, infrastructure, documentation, and internal tooling used to build and operate Shopyos.

Repositories are organized according to their purpose and access requirements.

## Development

Shopyos uses separate environments for development, testing, staging, and production.

Changes move through the development lifecycle using GitHub Issues, Projects, Pull Requests, code review, automated checks, and controlled deployments.

## Documentation

Technical documentation, architecture decisions, development standards, and operational guides are maintained within our GitHub organization.

## Building Shopyos

We are building Shopyos as more than a single marketplace. Our long-term goal is to create a technology platform capable of supporting multiple products and services.
